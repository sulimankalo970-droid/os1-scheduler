## Files Description
- scheduler.py: Main Python program implementing FCFS and Round Robin scheduling algorithms, Gantt chart generation, and performance comparison.
- input.txt: Group dataset containing processes (Arrival Time, Burst Time, Priority) and time quantum q.
- Report.pdf: Project report including execution screenshots, results table, and analytical comparison.

## How to Run
1. Ensure Python 3 is installed on your system.
2. Place input.txt in the same directory as scheduler.py.
3. Open the terminal in that directory and run:
   python scheduler.py
